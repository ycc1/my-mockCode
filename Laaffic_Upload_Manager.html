01 · API 連線設定

API Key 儲存於本機瀏覽器。勾選記住 Secret 時，Secret 也會儲存於 localStorage（未加密）；請勿用於共用裝置或正式營運。

02 · 上傳附件

支援 png / jpg / jpeg / bmp / gif / webp / psd / svg / tiff / mp3 / wav / txt / vcf
POST /v3/mmsUpload

RCS 發送接口的附件僅支援 PNG/JPG/JPEG。其他格式雖可透過上傳接口上傳，不代表可用於 RCS 發送。

03 · 已上傳附件紀錄

檔案名稱用途大小附件 ID上傳時間有效期限狀態操作

上傳成功的附件 ID 由 Laaffic 回傳。這裡僅保存上傳紀錄，不會自動同步其他電腦，也不會刪除 Laaffic 伺服器上的附件。已過期的附件請重新上傳。
